# project-templates

Start a Python, TypeScript, Rust, Go or Docker repository with this
[Copier](https://copier.readthedocs.io) template. Combine stacks when your project
needs more than one. Generated projects include tests, local checks and CI
workflows, with weekly pull requests to bring in template updates.

## Start your first project

1. [Choose your stacks](usage.md#choosing-your-stacks). For Python, compare the
   [project kinds](python-kinds.md) to find the layout that fits your work.
2. Follow the [quick start on GitHub](https://github.com/simonvanlierde/project-templates#quick-start)
   for the required tools and commands. Copier asks for your choices, then prints
   the setup steps for your new project.
3. Use the generated README to finish setup and run `just check`. See
   [keeping your project up to date](usage.md#keeping-your-project-up-to-date)
   when a new template release arrives.

Already have a repository? Follow
[adopting the template in an existing repo](usage.md#adopting-the-template-in-an-existing-repo).
